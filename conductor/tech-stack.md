# Technology Stack: Leafcloud App

## Frontend
- **Framework:** Flutter (Material Design) - Cross-platform UI development.
- **Language:** Dart - Fast, reactive programming for mobile and web.

## Libraries and Tools
- **Data Visualization:** `fl_chart` - High-performance graphing and analytics.
- **Network Communication:** `http` - Standard library for RESTful API integration.
- **Video Streaming:** `mjpeg_view` - Support for low-latency MJPEG video feeds.
- **State Management:** `provider` - Robust, scalable state management for real-time updates.
- **Internationalization:** `intl` - Support for localized content and formatting.
- **Code Quality:** `flutter_lints` - Standard linting for consistent and safe code.

## Architecture
- **Structure:** Standard Flutter project layout (`lib/` contains screens and core logic).
